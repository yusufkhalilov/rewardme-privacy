# RewardMe privacy policy

Public privacy-policy website for RewardMe by Aisbjo Software Solutions.

Publish the repository root from the `gh-pages` branch with GitHub Pages. The site is static HTML with inline CSS, no JavaScript, analytics, remote fonts or forms.

The policy is based on the existing RewardMe privacy policy and documented app features. Hosting-location and business-contact statements retain the information supplied in the app's existing policy. Keep those details, data practices and provider information current when operations change.
